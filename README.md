# 精神科問卷系統

## 簡介
這是一個為精神科醫生設計的問卷系統，旨在簡化尋找和使用精神科評估問卷的過程。本系統整合了常用的精神科評估工具，使醫生能夠更便捷地進行患者評估。

## 目前包含的問卷
- 貝克抑鬱量表 (BDI)
- 漢密爾頓抑鬱量表 (HAMD)
- 病人健康問卷-9 (PHQ-9)
- 廣泛性焦慮障礙量表-7 (GAD-7)
- 匹茲堡睡眠質量指數 (PSQI)

## 使用方法
1. 選擇所需的評估問卷
2. 按照指示完成問卷填寫
3. 系統將自動計算分數並提供初步解釋
4. 結果可以保存或導出為PDF格式
