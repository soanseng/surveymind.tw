# 精神科問卷系統

## 簡介
這是一個為精神科醫師設計的問卷系統，旨在簡化尋找和使用精神科評估問卷的過程。本系統整合了常用的精神科評估工具，使醫師能夠更便捷地進行評估。

## 使用方法
1. 選擇所需的評估問卷
2. 按照指示完成問卷填寫
3. 系統將自動計算分數並提供初步解釋
4. 結果可透過分享按鈕傳送

## 目前包含的問卷

### 情緒（6 份）
- GAD-7 廣泛性焦慮量表
- Zung 氏自我評估焦慮量表 (SAS)
- PHQ-9 憂鬱症篩檢問卷
- 台灣人憂鬱症量表 (TDQ)
- 輕躁症自我評估量表 (HCL-32)
- OCI-R 強迫症狀量表修訂版

### 睡眠（2 份）
- PSQI 匹茲堡睡眠品質量表
- ISI 失眠嚴重度量表

### 注意力不集中（2 份）
- ASRS 成人 ADHD 自我評估問卷
- SNAP-4 過動兒家長量表

### 認知功能（5 份）
- AD-8 早期失智篩檢表
- SPMSQ 簡易認知功能評估表
- SLUMS 聖路易大學心智狀態測驗
- CDR 臨床失智症評估量表說明
- FAST 功能性評估分級量表

### 人格（2 份）
- 大五人格量表 (Big-5)
- 麥克連邊緣性人格障礙症篩檢量表 (MSI-BPD)

### 創傷評估（2 份）
- PCL-5 創傷後壓力症候群檢核表
- PC-PTSD-5 初級照護 PTSD 篩檢量表

### 飲食評估（3 份）
- SCOFF 飲食障礙篩檢問卷
- EDE-Q 飲食障礙檢查問卷
- BES 暴食量表

### 成癮評估（5 份）
- AUDIT 酒精使用疾患識別測驗
- FTND 尼古丁依賴量表
- PGSI 問題賭博嚴重程度指數
- IGDS9-SF 網路遊戲障礙量表
- SAST 性成癮篩檢測驗
