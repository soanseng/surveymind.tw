

# **台灣失智症評估綜合指南：從自我篩檢到臨床分期**

## **導言：理解認知評估的工具**

失智症的評估是一個多層次的過程，涉及不同類型的工具，每種工具在評估過程中扮演著獨特的角色。為了正確使用並解讀這些工具，首先必須釐清其核心目的。評估工具大致可分為**篩檢工具**、**診斷性評估**及**分期工具**。篩檢工具，如問卷量表，旨在快速識別出可能存在認知問題的個案，提示需要進一步的專業評估 1。診斷性評估則是一個全面的臨床過程，由醫師整合病史、神經學檢查、實驗室檢驗及腦部影像等資訊，以確定病因並做出診斷 3。分期工具則用於衡量已確診個案的疾病嚴重程度與追蹤其病程變化 5。  
這些工具存在於一個「可及性 vs. 嚴謹性」的光譜上。有些工具設計簡單，便於公眾或家屬初步使用，可及性高但資訊較為概略；另一些工具則需要專業訓練才能執行與判讀，嚴謹性高但可及性較低。本報告旨在全面解析在台灣可取得的免費失智症評估量表，從最易於使用的社區篩檢工具，到臨床上用以診斷分期的專業量表，為使用者提供一份清晰、實用的指南。

## **第一部分：用於初步評估的免費篩檢工具（繁體中文版）**

本部分將詳細介紹在台灣最容易取得且經過驗證的免費篩檢工具，提供完整的題目、施測說明與計分方式，讓使用者能進行初步的自我評估或家人評估。

### **AD-8 (極早期失智症篩檢量表)：家屬評估的第一步**

AD-8量表是由美國聖路易華盛頓大學發展，並在台灣經過信效度驗證及廣泛推廣的篩檢工具 13。台灣衛生福利部國民健康署及各地方衛生局皆採用此量表作為社區極早期失智症篩檢的主力工具之一 8。其最大的特點是簡潔、快速，且對於偵測非常早期的認知功能  
**改變**具有極高的敏感度 2。雖然此量表版權屬華盛頓大學所有，但在台灣已獲合法授權，可供臨床及非營利研究使用 13。  
值得注意的是，AD-8並非傳統意義上的「自我評估」量表。它的設計初衷是由最了解個案的家屬或主要照顧者（即「知情者」）來填寫 1。這個設計背後的臨床理由至關重要：許多失智症患者會出現「病識感缺失」（Anosognosia）的症狀，也就是無法客觀認知到自身能力的衰退 17。因此，透過熟悉其過去與現在表現的親友來觀察「與過去相比是否有所改變」，能更有效地捕捉到早期的警訊。評估的重點並非個案「能不能」做到某件事，而是他「處理這件事的能力是否比幾年前變差了」。

#### **表2：AD-8 (極早期失智症篩檢量表) \- 完整題目、說明與計分 (zh-tw)**

施測說明：  
請詢問家屬或主要照顧者，並根據個案過去幾年的狀況與現在相較，是否有因為思考或記憶問題而產生下列改變。若有，請勾選「是，有改變」；若無，請勾選「否，沒有改變」；若不確定，則勾選「不知道」。

| 題號 | 問題內容 | 回答選項 |
| :---- | :---- | :---- |
| 1\. | **判斷力上的困難**：例如落入圈套或騙局、財務上不好的決定、買了對受禮者不合宜的禮物。 | □ 是，有改變 □ 否，沒有改變 □ 不知道 |
| 2\. | **對活動和嗜好的興趣降低**。 | □ 是，有改變 □ 否，沒有改變 □ 不知道 |
| 3\. | **重複相同的問題、故事和陳述**。 | □ 是，有改變 □ 否，沒有改變 □ 不知道 |
| 4\. | **在學習如何使用工具、設備和小器具有困難**。例如：電視、音響、遙控器、微波爐。 | □ 是，有改變 □ 否，沒有改變 □ 不知道 |
| 5\. | **忘記正確的月份和年份**。 | □ 是，有改變 □ 否，沒有改變 □ 不知道 |
| 6\. | **處理複雜的財物上有困難**。例如：個人或家庭的收支平衡、繳費單、所得稅。 | □ 是，有改變 □ 否，沒有改變 □ 不知道 |

| 8\. | **有持續的思考和記憶方面的問題**。 | □ 是，有改變 □ 否，沒有改變 □ 不知道 |

**計分與解釋：**

* 只計算「**是，有改變**」的項目，每項計為1分。「否，沒有改變」與「不知道」皆不計分。  
* 總分範圍為0至8分。  
* **若總分大於或等於2分 (≥2分)**，代表個案可能存在認知功能障礙的跡象，**建議應尋求神經內科或精神科醫師進行更詳細的專業評估** 18。

### **SPMSQ (簡易認知功能評估表)：直接的心智狀態測驗**

SPMSQ是另一種在台灣社區衛生單位廣泛使用的免費篩檢工具 9。與AD-8不同，SPMSQ是一份直接對長者進行提問的問卷，形式類似一個包含10個問題的小測驗，主要評估個案在時間、地點、個人資訊等方面的定向感與基本記憶力。它的優點是操作非常簡單，能快速得到結果。

#### **表3：SPMSQ (簡易認知功能評估表) \- 完整題目、說明與計分 (zh-tw)**

施測說明：  
直接向長者提問下列問題，並記錄其回答是否正確。

| 題號 | 問題內容 | 正確標準 |
| :---- | :---- | :---- |
| 1\. | 今天是幾號？ | 年、月、日都對才算正確。 |
| 2\. | 今天是星期幾？ | 星期對才算正確。 |
| 3\. | 這是什麼地方？ | 對所在地的任何描述都算正確（如「我的家」、醫院名稱）。 |
| 4\. | 您的電話號碼是幾號？ | 經確認號碼無誤即算正確。若無電話，可改問住址。 |
| 5\. | 您幾歲了？ | 年齡與出生年月日符合才算正確。 |
| 6\. | 您的出生年月日？ | 年、月、日都對才算正確。 |
| 7\. | 現任的總統是誰？ | 姓氏正確即可。 |
| 8\. | 前任的總統是誰？ | 姓氏正確即可。 |
| 9\. | 您媽媽叫什麼名字？ | 說出一個與他不同的女性姓名即可，不需特別證實。 |
| 10\. | 從20減3開始算，一直減3減下去。 | 20-3=17, 17-3=14, 14-3=11... 期間任何錯誤或無法繼續即算錯誤。 |

**計分與解釋：**

* 計分基礎為**答錯的題數**。  
* **錯0-2題**：心智功能完整。  
* **錯3-4題**：輕度心智功能障礙。  
* **錯5-7題**：中度心智功能障礙。  
* **錯8-10題**：重度心智功能障礙。  
* **若答錯三題以上 (≥3題)**，建議立即帶長者前往各大醫院的神經內科或精神科，進行進一步的失智症檢查 9。

### **SLUMS (聖路易大學心智狀態測驗)：更敏感的免費替代方案**

對於希望在就醫前獲得更深入資訊的使用者而言，聖路易大學心智狀態測驗（SLUMS）是一個極具價值的工具。它由美國聖路易大學開發，最大的優勢在於**完全免費**，且研究顯示其**對於偵測「輕度認知障礙」（Mild Cognitive Impairment, MCI）的敏感度優于傳統需要付費的簡易心智狀態檢查（MMSE）** 11。MCI被視為正常老化與失智症之間的中間階段，及早發現MCI對於採取干預措施、延緩病程至關重要。  
SLUMS已有翻譯且適用於台灣的版本，雖然其設計建議施測者應受過訓練，但其題目與說明相對清晰，知情的家屬在詳閱說明後，也能夠對測驗內容有相當程度的了解，並將觀察到的困難處記錄下來，作為與醫師溝通的具體依據 22。

## **第二部分：追蹤病情變化：理解失智症的分期**

當個案經過專業診斷確診為失智症後，評估的重點便從「篩檢」轉向「分期」與「追蹤」。分期工具的目的在於客觀地衡量疾病的嚴重程度，並追蹤其隨時間的進展。這對於規劃照護計畫、預期未來需求、以及申請相關社會資源至關重要。

### **臨床失智症評估量表 (Clinical Dementia Rating, CDR)：臨床分期的黃金標準**

CDR是由美國華盛頓大學開發，全球廣泛用於評估失智症嚴重程度的黃金標準工具 25。它並非一個簡單的問卷，而是一套半結構式的訪談，需要由受過訓練的臨床專業人員，同時訪談個案本人及一位熟悉他的家屬或照顧者，綜合兩方資訊後才能評分 5。CDR評估涵蓋六大功能領域：記憶力、定向感、判斷力與問題解決能力、社區事務、家居與嗜好、以及個人照料 27。  
在台灣，CDR不僅是臨床上重要的評估工具，更具有實際的行政功能。它是申請重要長照資源的「鑰匙」。根據台灣的規定，**CDR分數達0.5分以上是申請失智共照中心服務的條件之一** 29，而  
**CDR分數達1分（含）以上，則是申請外籍家庭看護工的必要條件** 30。因此，了解CDR的評估內容，能幫助家屬理解臨床醫師的評估重點，以及為何某些服務的申請需要此項評估。

### **功能性評估分級量表 (Functional Assessment Staging Tool, FAST)：功能退化的實用指南**

FAST量表是另一個重要的分期工具，它特別聚焦於阿茲海默症患者在日常生活中**功能性能力**的退化順序 6。此量表的特點在於其描述的退化過程具有高度的可預測性與順序性，從複雜的財務管理能力喪失，一路到基本的穿衣、沐浴、行走能力的退化。這對家屬而言，是一份非常直觀且實用的指南，能幫助他們預期下一階段可能出現的照護需求，並提前做好準備 31。在臨床上，FAST的後期階段（特別是第7期）也常用於評估安寧療護的適用性 6。

#### **表7：功能性評估分級量表 (FAST) \- 七個階段功能描述**

| 階段 | 嚴重程度 | 功能描述 |
| :---- | :---- | :---- |
| **1** | 正常成人 | 沒有客觀或主觀的功能困難。 |
| **2** | 正常老化 | 主觀感覺找詞困難或忘記物品位置。 |
| **3** | 輕度認知障礙 | 在要求高的工作或社交場合中出現功能困難。同事意識到其工作表現下降。 navigating new locations becomes challenging. |

## **第三部分：關於其他臨床常用量表的說明**

在臨床評估過程中，家屬可能還會聽到其他評估工具的名稱。簡要了解這些工具，有助於更全面地掌握評估情境。

### **MMSE (簡短式智能評估) 與 MoCA (蒙特利爾認知評估)**

* **MMSE (Mini-Mental State Examination)**：在過去數十年是全球最廣泛使用的認知評估工具 5。然而，近年來其地位面臨挑戰，主要原因有二：首先，它對於偵測輕度認知障礙（MCI）的敏感度不足 11；其次，它已成為一項  
  **專有工具，每次使用皆須支付版權費用**，因此不符合「免費使用」的範疇 11。  
* **MoCA (Montreal Cognitive Assessment)**：此工具因其在篩檢MCI方面的高敏感度而受到重視 35。然而，其版權方  
  **嚴格要求所有使用者必須完成官方的線上培訓與認證**才能合法施測 37。這項規定使其不適用於一般民眾的自我評估，而是一個專業人員使用的臨床工具。

## **第四部分：台灣照顧者實用指南：從篩檢到行動**

了解評估工具後，更重要的是知道下一步該怎麼做。本部分將提供一個清晰的路徑圖，指導家屬如何在篩檢結果異常後，有效地尋求醫療協助，並在診斷過程中扮演好關鍵角色。

### **篩檢之後：在台灣的診斷路徑**

當初步篩檢（如AD-8或SPMSQ）結果提示有風險時，應採取以下步驟：

1. **預約門診**：應掛號**神經內科**或**精神科（身心科）**。神經內科專精於大腦結構與功能的退化性疾病，而精神科則擅長處理伴隨失智而來的行為與情緒問題。許多醫院設有整合性的「**記憶門診**」，是理想的初診選擇 4。  
2. **接受完整臨床評估**：醫師的診斷過程通常包括：  
   * **詳細問診**：詢問症狀開始時間、生活變化、過去病史與家族史。家屬提供的資訊至關重要 4。  
   * **抽血檢查**：排除其他可能導致認知功能下降的可逆性原因，如維生素B12缺乏、甲狀腺功能異常或感染等 35。  
   * **腦部影像學檢查**：通常會安排電腦斷層（CT）或磁振造影（MRI），以觀察是否有腦萎縮、中風、腦瘤或水腦等結構性問題 1。  
   * **正式認知功能評估**：由臨床心理師或受過訓練的專業人員施測更詳細的評估工具，如MMSE、CASI或CDR 30。  
3. **連結支持系統**：一旦確診，應立即聯繫各縣市的「**失智共同照護中心**」（失智共照中心）。這是台灣失智症照護網絡的核心，提供個案管理、資源轉介、家屬支持與諮詢等一站式服務 42。部分醫院與共照中心合作提供「  
   **快速通關**」服務，能縮短確診所需的時間 44。

### **照顧者的關鍵角色：如何有效與醫療團隊溝通**

在整個診斷與治療過程中，照顧者是醫療團隊最重要的夥伴。一份清晰、具體的觀察紀錄，其價值遠勝於模糊的描述。與其告訴醫師「他記性不好」，不如提供「他上週有三天忘記吃降血壓藥，而且重複問了五次今天是不是星期三」。這種具體的資訊能為醫師提供判斷的堅實依據。  
為了協助照顧者有效地記錄與溝通，建議建立一份「照顧者觀察日誌」。這份日誌不僅能幫助您在看診時有條理地陳述，也能讓您客觀地追蹤病情變化。

### **主動的腦部健康策略：預防與延緩病程**

無論是對於健康長者、MCI患者，或是已確診的早期失智症患者，採取積極的生活方式干預，都能有效增加大腦的「認知儲備」，進而預防或延緩失智症的發生與惡化。台灣國民健康署推廣的「**護腦5招**」提供了明確的指引 45：

1. **多動腦**：從事可刺激大腦功能的活動，如閱讀、學習新知、玩益智遊戲、打麻將等 47。  
2. **多運動**：每週進行至少150分鐘的中等強度有氧運動（如快走、游泳），研究證實規律運動能顯著降低認知退化風險 49。  
3. **多社會互動**：積極參與社區活動、與親友保持聯繫，避免社交孤立 45。  
4. **均衡飲食**：採行地中海式或得舒（DASH）飲食，多攝取蔬菜、水果、全穀類、白肉與堅果，有助於保護心血管與大腦健康 49。  
5. **維持健康體重**：特別是避免中年肥胖，因為這與晚年失智風險增加有顯著關聯 49。

此外，**戒菸**與**避免過量飲酒**也是經證實能保護大腦健康的重要措施 49。

## **結論：以知識與行動賦能家庭**

面對失智症的挑戰，知識是賦予家庭力量的第一步。本報告詳細介紹了在台灣可免費取得的失智症篩檢工具，包括適用於家屬觀察的**AD-8**、直接測試的**SPMSQ**，以及更為敏感的**SLUMS**測驗。這些工具為民眾提供了初步評估的管道。  
然而，必須強調，**任何篩檢工具的結果都不能取代正式的臨床診斷** 1。它們的功能是作為警示燈，提醒我們何時應該尋求專業協助。當篩檢結果呈現異常時，應及時至神經內科或精神科就診，接受完整的評估。  
了解如**CDR**和**FAST**等臨床分期工具，能幫助家屬理解失智症的病程，並為未來的照護需求做好準備。更重要的是，在台灣，CDR評分是獲取外籍看護等關鍵長照服務的依據，顯示了準確評估的現實重要性。  
最終，及早發現、及早診斷、及早介入是應對失智症的核心策略。透過積極的生活方式調整，結合台灣完善的失智共照中心網絡所提供的支持，失智者及其家庭能夠更有效地管理疾病，延緩功能退化，並維持更佳的生活品質。這是一條漫長的道路，但藉由正確的知識與積極的行動，家庭可以更有信心地前行。
